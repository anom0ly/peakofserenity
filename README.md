# Peak of Serenity

Source for peakofserenity.com, moving from WordPress/Divi to Docusaurus (hosted on Cloudflare Pages,
edited with Pages CMS).

- `docs/` guides (one `.mdx` per guide; tab content lives in front-matter fields)
- `blog/` news posts (`YYYY-MM-DD-slug.mdx`), `blog/authors.yml` and `blog/tags.yml` (tag page addresses)
- `podcast/` podcast episodes (`YYYY-MM-DD-slug.mdx`); the podcast feed is `static/podcast/feed.xml`
- `migration/` inventory, review list of things that didn't convert cleanly, and old → new URL maps
- `src/` site code: guide layout (`components/GuideTabs`, `guideTypes.json`), homepage, spec hubs, theme
- `static/img/uploads/` images, same paths as `wp-content/uploads/`
- `.pages.yml` the Pages CMS editor setup (generated by `tools/pages_config.py`)
- `tools/` the WordPress export converters
- `STATUS.md` where the migration stands

## Running the site

```sh
npm ci
npm start          # local preview at http://localhost:3000
npm run build      # what Cloudflare Pages runs; output in build/
```

## Migration mode (temporary barebones site)

Two Cloudflare Pages environment variables (Settings → Variables and Secrets → Production), then redeploy:

- `MIGRATION_MODE=true` builds only the landing page ("we're moving"), the three spec guides and the Windwalker
  guide's sub-pages. Every other address shows a "this page hasn't moved over yet" page. Remove it (or set it to
  anything else) and redeploy to bring the full site back; no content is deleted.
- `PODCAST_MEDIA_URL=<public address of the R2 bucket "podcasts">` (no trailing slash) points the podcast feed's
  MP3 links at R2 and redirects old `/wp-content/uploads/...` addresses there. It works in either mode.

```sh
MIGRATION_MODE=true PODCAST_MEDIA_URL=https://media.example.com npm run build
```

## Re-running the conversion

```sh
python3 -m pip install beautifulsoup4 markdownify pyyaml pillow
python3 -I tools/inventory.py path/to/export.xml migration
# --skip-existing never overwrites a file that is already there (pages authors have edited stay as they are)
python3 -I tools/wp2mdx.py path/to/export.xml . --all --skip-existing
python3 -I tools/fetch_images.py .      # downloads images from the live site; run after wp2mdx (it re-adds failures to the review list)
python3 -I tools/compress_images.py .   # shrinks new images in place
python3 -I tools/pages_config.py .      # rewrites .pages.yml from src/guideTypes.json and blog/authors.yml
```
